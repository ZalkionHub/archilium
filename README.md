# Archilium: El Reino Sucumbido

Website oficial de presentación en castellano de un RPG de acción en pixel art, actualmente en desarrollo.

[Visitar Archilium](https://zalkionhub.github.io/archilium/)

Este repositorio contiene la web estática: personajes, propuestas de razas, bestiario, reinos y magia, materiales de presentación y reproductor musical. GitHub Pages sirve `main` desde la raíz. No necesita instalar dependencias para visualizarse desde un servidor HTTP.

Las razas y criaturas se presentan como conceptos en desarrollo. Las ilustraciones conceptuales y animaciones de marca se distinguen de la captura real del prototipo. Fecha de lanzamiento y página de Steam por anunciar.

Consulta [la procedencia y los créditos de los recursos](ATTRIBUTIONS.md). La publicación del repositorio no concede una licencia general de reutilización de la marca, música o materiales.
